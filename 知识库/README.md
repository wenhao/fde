## 四部文献的关系（一句话版）

- **资料 1（许良）**回答"FDE 这件事**怎么做**"——最细的实操手册；
- **资料 2（场景学社）**回答"FDE 在**制造业**怎么落地"——唯一深入工业场景，提出 FDE+FDR 双轮；
- **资料 3（腾讯研究院）**回答"FDE 为什么成立、**组织与商业**怎么设计"——机制分析最深，数据最新；
- **资料 4（史凯 Lean-FDE）**提出一套**成体系的训练与成熟度框架**——九大能力域 × 训战关卡 × M0-M5。

四者视角互补，核心共识高度一致：**AI 落地的瓶颈不在模型，在交付断层；FDE 的价值在沉淀可复用资产，而非卖人天。**
